# Greenshot sprints 1 through 4

1. Validation: added real export-source workflow checks for filename/review cancellation, confirmed overwrite, final-format changes, and separate automatic palette caches. Fixed an omitted automatic color-reduction cache key. Native mouse, keyboard, mixed-monitor, and Photoshop acceptance remains pending because native Windows automation is unavailable.
2. Profiles: independent custom-profile editing, rename, built-in duplication, summary, and transactional portable XML import/export. Built-ins remain protected. Twenty-profile and storage limits remain.
3. Export review: Review and Save As offers a per-save decision after the actual filename and format are selected. It shows the target, format, rendered dimensions, supported DPI, print size, and compression. Unsupported formats identify DPI scope.
4. Upgrades: stable launcher pointer, checksum verification before pointer changes, first-upgrade preference backup/migration after normal Exit, shared settings/logs, previous-pointer backup, and local diagnostics. No process is force-stopped and no installed preference is overwritten.

Verification records are local. Test counts and exact source provenance are recorded in the release manifest and whitepaper. Existing analyzer warnings and the unretested full dependency-restore graph remain. Native acceptance is a separate open gate, not evidence supplied by offscreen rendering or simulated launcher processes.
